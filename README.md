# CodeAlpha_StockPortfolioTracker

**Task 2 — Stock Portfolio Tracker** (CodeAlpha Python Programming Internship)

A simple console app that calculates total investment value based on
manually entered stock names/quantities and hardcoded stock prices.

## Features
- Hardcoded dictionary of stock prices (e.g. AAPL, TSLA, GOOGL...)
- User enters stock symbols and quantities interactively
- Calculates subtotal per stock and total investment value
- Optionally saves the summary as a `.txt` or `.csv` file

## Concepts Used
Dictionaries, input/output, basic arithmetic, file handling (`csv` module)

## How to Run
```bash
python stock_tracker.py
```
